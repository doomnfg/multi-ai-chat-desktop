# PSD 教育訓練：Claude Code 上手

> Agentic 工作模式 × Prompt × Skill 設計｜半天課程（3.5 小時）

## 課程對象

- PSD 部門同仁（大型硬體設備進場安裝與驗收）
- AI 完全新手
- 設備範圍：IBM Power（AIX）、x86 伺服器（RHEL）
- 使用環境：個人電腦（Windows）＋ Claude Code

## 教材結構

```
psd-claude-code/
├── README.md                 ← 本檔：教材總覽與講師準備

├── 練習題/                   ← 發給學員（複製到學員電腦）

```

## 講師課前準備清單

### 上課前一週

- [ ] 確認每位學員都有 Claude Code 可用的帳號（Pro、Max、Team、Enterprise 或 Console；免費版不含 Claude Code）
- [ ] 寄發課前通知：請學員依《學員講義》「課前準備」安裝 Claude Code，並完成第一次登入
- [ ] 將 `練習題/` 資料夾打包成 zip，連同《學員講義》一起發給學員
- [ ] 依公司資安政策，確認模組 4「四條紅線」的內容

### 上課當天

- [ ] 講師電腦已安裝 Claude Code，並先跑過三個練習
- [ ] 準備投影：簡報＋終端機畫面（建議放大終端機字體）
- [ ] 準備備用帳號，讓無法登入的學員先和旁邊同學一組

### 需要補上的佔位文字

| 位置 | 佔位文字 |
|---|---|
| 簡報封面、結尾 | `[講師姓名]`、`[YYYY/MM/DD]`、`[分機／Email]` |
| 簡報模組 4 | `[公司資安政策名稱]` |
| 學員講義 | `[IT 窗口]`、`[繳交方式]`、`[截止日期]` |

## 注意事項

- 所有練習資料都是**模擬資料**，序號、型號配置、測試數據均為虛構
- CSV 檔使用 UTF-8（含 BOM）編碼，可以直接用 Excel 開啟，中文不會亂碼
- `講師解答/` 內含答案，發放教材時請排除這個資料夾
