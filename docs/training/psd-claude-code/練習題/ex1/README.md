# 練習 1：改寫 Prompt — 進場前機房條件確認表

⏱ 15 分鐘

## 情境

下週要到客戶機房安裝下列設備，進場前要先和客戶確認機房條件：

- IBM Power 主機 2 台（AIX）
- x86 伺服器 4 台（RHEL）

## 原始 Prompt

```
幫我列機房要確認的東西
```

## 你的任務

1. 用**六要素**（角色、背景、任務、限制、格式、範例）改寫這個 Prompt
2. 在 `ex1` 資料夾啟動 `claude`，先把**原始版**交給 Claude，看看結果
3. 輸入 `/clear` 清除對話，再把**改寫版**交給 Claude
4. 比較兩份結果，記下差異

## 改寫範本

```
【角色】
【背景】
【任務】
【限制】
【格式】
【範例】（可省略）

資訊不足時先問我，不要自己猜。
```

## 提示

- **限制**可以寫：只列出需要客戶確認的項目；不確定的規格數值不要自己填
- **格式**可以寫：表格，欄位為「類別／確認項目／需求說明／客戶回覆」
- 想一想機房確認通常包含哪些類別：機櫃空間、電力、空調、承重、網路、搬運路線、進場管制……

## 評分重點

- [ ] 六要素是否齊全（範例可省略）
- [ ] 結果能否直接印出，給客戶逐項勾選
- [ ] AI 有沒有自己編出規格數字（例如耗電量）？有的話，限制要再寫清楚
