# 練習 2：到貨點收比對 — 產出差異報告

⏱ 25 分鐘

## 情境

客戶專案的設備到貨了，但訂單上應到的設備，和現場掃描的點收結果不完全一致。請用 Claude Code 找出所有差異，產出差異報告。

## 練習資料

| 檔案 | 內容 | 欄位 |
|---|---|---|
| `input/採購清單.csv` | 訂單應到貨的設備（含原廠裝箱單資訊） | 項次、箱號、料號、品名、數量、序號 |
| `input/點收清單.csv` | 現場掃描的點收結果 | 箱號、料號、品名、實收數量、掃描序號、點收時間、點收人 |

> 所有資料都是教育訓練用的模擬資料。

## 操作步驟

1. 在 PowerShell 切換到練習資料夾並啟動：

    ```powershell
    cd D:\AI-Work\練習\ex2
    claude
    ```

2. （選做）輸入 `/init` 產生 CLAUDE.md，或依講義範本自己建立，寫入「不可修改 input/ 的原始檔」等規則
3. 按 `Shift + Tab` 切換到 **Plan Mode**
4. 用六要素交代比對任務，產出到 `output/差異報告.md`
5. **審核計畫**：比對基準是什麼欄位？會不會誤判？確認後再執行
6. 開啟 `output/差異報告.md` 檢查結果
7. 用講義的「四項抽查」驗證結果

## 提示

- 想一想：比對時要用哪個欄位當基準？**箱號、料號，還是序號？** 不同的基準，可能得到不同的結論
- 差異可能有這幾種：缺件、多出、序號不符、數量不符
- 沒有序號的配件（例如線材）要怎麼比對？
